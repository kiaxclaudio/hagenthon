# Inbox

Punto di ingresso per i documenti che arrivano da fuori: il file di Chiara con la struttura
dell'idea, note, materiali di partenza, l'artefatto reale su cui lavoriamo.

Qui i file si **depositano**, non si modificano. Vengono letti e il loro contenuto viene
distribuito nei file giusti del repo (agenti, schemi, README, presentazione). L'originale resta
qui come traccia: serve a ricostruire da dove viene una decisione, e alla nota sul processo.

Convenzione di nome: `<autore>-<argomento>.md`, per esempio `chiara-idea.md`.

Nota su `docs/IDEA-INTAKE.md`: non e un doppione di quanto porta Chiara. E la lista di cosa
serve alla struttura per funzionare. Se il documento di Chiara copre gia tutto, l'intake si
butta; se resta scoperto qualcosa, dice esattamente cosa manca ancora.
